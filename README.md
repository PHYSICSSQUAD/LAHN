# لحن — نتعلم ونرنم معا

منصة تعليمية عربية مرحة لأطفال مدرسة الشمامسة وأسرهم، مبنية بـ **HTML وCSS وVanilla JavaScript** فقط. الواجهة RTL بالكامل، وتعمل كتطبيق صفحة واحدة خفيف بروابط hash؛ لا تحتاج إلى خادم تطبيق أو build step، وجاهزة للنشر كملفات static على Vercel.

الموقع يخدم **ثلاثة فصول** (Baby Class وKG1 وKG2) من نفس الكود: صفحة اختيار أولى، ولكل فصل ثيمه اللوني وملاكه ومحتواه.

> **الموقع للعرض فقط.** لا توجد لوحة إدارة ولا تسجيل دخول ولا رفع ملفات من المتصفح. كل المحتوى (الألحان وكلماتها، دروس الطقس، الحروف القبطية، المنهج، بيانات التواصل) مكتوب في ملفات المشروع ويعدل من الكود. المتصفح يحفظ شيئا واحدا فقط: **نجوم الطفل** وآخر فصل تم فتحه.

## الجديد في هذه النسخة

- **كلمات كل لحن بالعربي والقبطي المعرب** جنبا إلى جنب في عمودين (القبطي المعرب = نطق الكلمات القبطية مكتوبا بحروف عربية).
- **رابط لنفس اللحن بصوت المعلم إبراهيم عياد** في صفحة كل لحن.
- **مصادر موثقة** لكل لحن ولكل درس طقس وللحروف القبطية (مواقع كلمات الألحان، ملفات المنهج PDF، روابط Google Drive ويوتيوب).
- أزيلت **لوحات الإدارة وحسابات الدخول** وقسم **«تسجيلي»** الذي كان يرفع فيه الأهل تسجيلاتهم.

## تشغيل المشروع محليا

تحتاج إلى Python 3 أو أي خادم static بسيط. من مجلد المشروع:

```bash
python3 -m http.server 4173
```

ثم افتح <http://localhost:4173>. لا تفتح `index.html` مباشرة عبر `file://` لأن المتصفح يمنع وحدات JavaScript هناك.

لا توجد تبعيات npm ولا أمر build.

## الفصول الثلاثة

| الفصل | الثيم | الأيقونة | الملاك (SVG) | الصفحة |
| --- | --- | --- | --- | --- |
| Baby Class | وردي | 🍼 | `assets/images/angel-babyclass.svg` (الدبدوب) | `#/babyclass/home` |
| KG1 | أخضر نعناعي | 🎈 | `assets/images/angel-kg1.svg` (الكتاب) | `#/kg1/home` |

محتوى كل فصل في `js/data.js`:

- **KG1 وKG2:** 3 ألحان (مرد إنجيل كيهك «تين تي ني إمبي»، ختام الصلوات، لحن بارك)، 3 دروس من كتاب «الكنيسة أمي» (المعمودية والميرون والتوبة)، ونفس الحروف الستة.
- تسجيلات المدرسة المتاحة موجودة في `assets/audio/` (`Babyclass-1.ogg` و`KG1-1.ogg` و`KG2-1.mp4`)، وباقي الألحان يستمع إليها من رابط المعلم إبراهيم عياد.

## المسارات

| المسار | الوصف |
| --- | --- |
| `#/` | صفحة اختيار الفصل: ثلاث بطاقات |
| `#/<class>/home` | رئيسية الفصل بثيمه وملاكه وبطاقات محطاته |
| `#/<class>/hymns` · `#/<class>/hymn?id=…` | الألحان وتفاصيل اللحن (الكلمات + إبراهيم عياد + المصادر) |
| `#/<class>/coptic` · `#/<class>/letter?id=…` | الحروف القبطية وتفاصيل الحرف وورقة العمل |
| `#/<class>/liturgy` · `#/<class>/ritual?id=…` | دروس الطقس وتفاصيل الدرس |
| `#/<class>/curriculum` | المنهج: الألحان والطقس والقبطي مع المدة والمرجع وروابط المصادر |
| `#/contact` | صفحة «تواصل معي» |

حيث `<class>` هو `babyclass` أو `kg1` أو `kg2`.

**الروابط القديمة بدون فصل** (`#/hymns`، `#/coptic`، `#/hymn?id=…` …) تكمل تلقائيا في **آخر فصل تم فتحه** على هذا المتصفح، وإن لم يكن هناك فصل سابق تظهر صفحة اختيار الفصل. **روابط الإدارة القديمة** (`#/admin` و`#/<class>/admin`) تعيد التوجيه إلى رئيسية الفصل أو صفحة الاختيار، كما تمسح النسخة الجديدة بيانات الإدارة القديمة من المتصفح مرة واحدة تلقائيا.

## صفحة اللحن

كل لحن يعرض:

1. **كلام اللحن** في عمودين: «عربي» و«قبطي معرب».
2. **بصوت المعلم إبراهيم عياد** — رابط يوتيوب لنفس اللحن.
3. **اسمع اللحن** — مشغل صوت لتسجيل المدرسة إن وجد، وإلا رسالة تحيل إلى المصادر.
4. **مصادر اللحن** — روابط مواقع الكلمات (مدرسة الشمامسة، St-Takla…) وملف المنهج PDF.
5. **ملاحظات** — متى يقال اللحن ومعلومة قصيرة عنه.

## صفحة «تواصل معي» — `#/contact`

- رابطها في ترويسة وتذييل كل الصفحات.
- تعرض: الاسم، الصفة، رسالة الترحيب، الهاتف، واتساب، البريد الإلكتروني، فيسبوك، العنوان، ومواعيد التواصل.
- الروابط تفاعلية: `tel:` للهاتف، `https://wa.me/<number>` للواتساب، `mailto:` للبريد، ورابط فيسبوك بعد التحقق من النطاق.
- بياناتها ثابتة في `SITE_CONTACT` داخل `js/config.js` (القيم الحالية **أمثلة**؛ استبدلها ببيانات المدرسة الحقيقية قبل النشر).

### ما الذي يحفظ في المتصفح؟

| المفتاح | المحتوى |
| --- | --- |
| `lahn-progress-v1:<class>` | النجوم التي جمعها الطفل في هذا الفصل |
| `lahn-last-class-v1` | آخر فصل تم فتحه، لتكملة الروابط القديمة |

لا شيء آخر يحفظ، ولا يرسل أي بيانات إلى خادم.

## تعديل المحتوى

كل التعديلات تتم في الكود ثم تنشر:

- **لحن جديد أو تعديل لحن:** `js/data.js` — الحقول: `id`, `title`, `copticTitle`, `description`, `icon`, `order`, `lyricsArabic`, `lyricsCoptic`, `notes`, `audioSrc`, `ayad: { label, url }`, `sources: [{ label, url }]`.
- **درس طقس:** `title`, `description`, `body`, `notes`, `icon`, `order`, `sources`.
- **حرف قبطي:** `glyph`, `name`, `transliteration`, `word`, `translation`, `note`, `order`, `sources`.
- **المنهج:** مصفوفات `BABY_CURRICULUM` و`KG_CURRICULUM` (`title`, `goal`, `points`, `duration`, `reference`, `links`).
- **الروابط المتكررة** (ملفات PDF وGoogle Drive ومواقع الكلمات) مجمعة في الثابت `SOURCE` أعلى `js/data.js`.
- **اسم المدرسة في الشريط العلوي وبيانات التواصل:** `js/config.js`.

روابط يوتيوب تمر على `safeYouTubeUrl` (نطاقات يوتيوب فقط)، وباقي الروابط تقبل `https` أو ملفا داخل `assets/` فقط.

## النشر على Vercel

1. اربط مستودع GitHub بمشروع جديد في Vercel.
2. اترك Framework على **Other**، وBuild Command وOutput Directory فارغين.
3. انشر المستودع كما هو؛ `index.html` هو نقطة الدخول، والروابط الداخلية `#/...` فلا تحتاج rewrite.

لا توجد متغيرات بيئة ولا أسرار في الكود.

## الوصول والاستجابة

- اللغة الأساسية عربية واتجاه الصفحة `rtl`، مع خط Tajawal وخط Coptic من Google Fonts وبدائل نظامية.
- تخطيط مرن للهاتف واللوحي والحاسوب، وأهداف لمس واضحة، وتركيز لوحة مفاتيح مرئي.
- أنيميشن قصيرة مع احترام `prefers-reduced-motion`.
- ألوان كل فصل عبر متغيرات CSS على `html[data-class]`، ويتغير `theme-color` مع الفصل المفتوح.
- زر **اطبع الورقة** يطبع ورقة الحرف فقط عبر `@media print`.

## اختبار سريع بعد التعديل

1. من `#/` افتح الفصول الثلاثة وتأكد من اختلاف الثيم والملاك وظهور شريط اسم المدرسة.
2. افتح كل لحن وتأكد من ظهور عمودي «عربي» و«قبطي معرب»، ورابط المعلم إبراهيم عياد، وقائمة المصادر.
3. شغل تسجيل المدرسة في اللحن الأول لكل فصل، وتأكد من رسالة «لا يوجد تسجيل للمدرسة هنا» في باقي الألحان.
4. افتح درس طقس وحرفا قبطيا وتأكد من ظهور مصادرهما، وجرب طباعة ورقة الحرف.
5. جرب رابطا قديما (`#/hymns` أو `#/admin`) وتأكد أنه يكمل في آخر فصل مفتوح أو يعود لصفحة الاختيار.
6. اجمع نجمة، حدث الصفحة، وتأكد من بقائها.
7. افتح DevTools Console لمراجعة أي أخطاء أو ملفات غير متاحة.
