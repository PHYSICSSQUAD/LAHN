# لحن — نتعلم ونرنم معا

منصة تعليمية عربية مرحة للأطفال والأسرة، مبنية بـ **HTML وCSS وVanilla JavaScript** فقط. الواجهة RTL بالكامل، وتعمل كتطبيق صفحة واحدة خفيف بروابط hash؛ لا تحتاج إلى خادم تطبيق أو build step، وجاهزة للنشر كملفات static على Vercel.

> **مهم:** هذه النسخة تعمل بنمط العرض المحلي. محتوى الإدارة والملفات المرفوعة يحفظ في متصفح الجهاز الحالي فقط، ولا ينتقل تلقائيا إلى زوار الموقع أو أجهزة أخرى. كما أن دخول الإدارة في واجهة أمامية وحدها ليس وسيلة حماية حقيقية. راجع قسم [التخزين والأمان](#التخزين-والأمان-والنسخة-الحالية) قبل نشر بيانات حقيقية.

## تشغيل المشروع محليا

تحتاج إلى Python 3 أو أي خادم static بسيط. من مجلد المشروع:

```bash
python3 -m http.server 4173
```

ثم افتح <http://localhost:4173>. لا تفتح `index.html` مباشرة عبر `file://` لأن المتصفح يمنع بعض وحدات JavaScript وميزات التخزين هناك.

لا توجد تبعيات npm ولا أمر build.

## النشر على Vercel

1. اربط مستودع GitHub بمشروع جديد في Vercel.
2. اترك إعدادات Framework على **Other**، وBuild Command وOutput Directory فارغين/افتراضيين.
3. انشر مجلد المستودع كما هو؛ `index.html` هو نقطة الدخول، والروابط الداخلية تستخدم `#/...` فلا تحتاج إلى إعداد rewrite.

**متغيرات البيئة:** لا توجد متغيرات مطلوبة في النسخة الحالية. لا تضع مفاتيح أو أسرارا في JavaScript للمتصفح.

> النشر على Vercel لا يحول `localStorage` أو IndexedDB إلى قاعدة بيانات مشتركة. يرى كل زائر بيانات المتصفح الخاص به؛ لذلك يلزم ربط Backend قبل استخدام الموقع كمصدر محتوى مشترك.

## دخول لوحة الإدارة — نسخة العرض

يوجد دخول واحد للمدير فقط، ولا توجد حسابات دخول للأهل. إعدادا اسم المستخدم وكلمة المرور موجودان **مرة واحدة فقط** داخل `APP_CONFIG.admin` في `js/config.js`. راجع القيم الحالية هناك للتجربة، وغيرها من هذا الموضع وحده. بعد فتح الموقع، استخدم رابط **دخول الإدارة** في أعلى الصفحة أو **لوحة الإدارة** في التذييل.

اسم المدرسة الظاهر في الشريط العلوي لكل الصفحات («مدرسة شمامسة كنيسة الشهيد العظيم ابي سيفين بحدائق القبة») يضبط من `APP_CONFIG.siteBanner` في الملف نفسه `js/config.js`.

**هذه ليست مصادقة آمنة:** بيانات الدخول موجودة في ملفات JavaScript التي تصل إلى المتصفح، ويمكن تجاوزها من أدوات المطور. لا تستخدم كلمة مرور حقيقية ولا تعتمد عليها لحماية موقع عام. يتم حفظ علامة الدخول في `sessionStorage` وتنتهي عند إغلاق جلسة المتصفح.

## ما الذي يعمل في الموقع؟

- الرئيسية: بطاقات كبيرة للألحان والطقس والقبطي، ولوحة أبطال مرتبة تلقائيا بالنقاط.
- الألحان: بطاقات قابلة للإدارة، وصفحة تفاصيل بها مشغل صوت، مصدر يوتيوب، كلمات، تسجيل إضافي وملاحظات.
- القبطي: مجموعة الحروف التجريبية، صفحات للحرف والصوت/المثال/الترجمة، ورقة عمل قابلة للطباعة، ورابط مصدر عام.
- الطقس: دروس قصيرة قابلة للإضافة والتحرير، مع نص وصوت وملاحظات وصور ومصدر يوتيوب.
- دخول واحد للمدير فقط: إدارة الطلاب والألحان والحروف ومصادر يوتيوب ودروس الطقس الكنسي؛ إضافة وتعديل وحذف وترتيب، مع تأكيد قبل الحذف.
- تعديل نقاط الطلاب بخطوات ثابتة فقط: +20 أو +50 أو +100، ويمكن الخصم بالقيم نفسها. يعاد ترتيب لوحة الأبطال تلقائيا.
- مشغل صوت HTML5 موحد بعملية تشغيل/إيقاف مؤقت وشريط تقدم ووقت.
- رفع صور مضغوطة إلى WebP (حيث يدعم المتصفح ذلك)، وصوت وملفات PDF/صور لورقة العمل.
- الروابط الخارجية تفتح في نافذة جديدة وتقبل روابط YouTube / youtu.be الآمنة فقط.
- التغييرات المحفوظة والنجوم التعليمية تبقى بعد تحديث الصفحة على المتصفح نفسه.

## بنية المشروع

```text
.
├── index.html                 # تطبيق RTL ونقطة الدخول
├── css/main.css               # التصميم المتجاوب، المكونات والطباعة
├── js/
│   ├── app.js                 # التوجيه، الصفحات وتفاعلات الطفل
│   ├── admin.js               # تسجيل الدخول التجريبي وCRUD لوحة الإدارة
│   ├── components.js          # الترويسة والتذييل ومشغل الصوت
│   ├── config.js              # إعداد مركزي: اسم المدرسة في الشريط العلوي وبيانات دخول نسخة العرض
│   ├── data.js                # محتوى البداية التجريبي (seed)
│   ├── storage.js             # واجهة التخزين المحلية وIndexedDB للوسائط
│   └── utils.js               # الفرز، الروابط الآمنة، تنسيق وعرض النصوص
├── assets/
│   ├── images/angel.svg        # ملاك لطيف للصفحة الرئيسية
│   ├── images/coptic-fish.svg  # سمكة تعليمية لقسم القبطي
│   └── audio/demo-tone.wav     # نغمة اختبار قصيرة وليست لحنا أو نطقا حقيقيا
├── favicon.svg
└── README.md
```

### شكل البيانات

تحفظ سجلات المحتوى ككائن واحد بإصدار في `localStorage`، وتحمل أمثلة البداية من `js/data.js` عند أول زيارة. تشمل المجموعات `students`, `hymns`, `copticLetters`, `liturgy`, `settings`, و`progress`. كل سجل له `id` و`order`، ودرجات الطلاب تفرز تنازليا تلقائيا. حقول الوسائط تشير إلى معرفات IndexedDB بدل وضع الملفات الثنائية في HTML أو JSON.

هذه الواجهة معزولة في `storage.js` لتسهيل استبدالها لاحقا بـ API وقاعدة بيانات من دون إعادة كتابة صفحات العرض.

## إدارة المحتوى

- **الأبطال والنقاط:** أضف أو حرر اسم الطالب. يبدأ الطالب الجديد بصفر، وتعديل النقاط متاح بخطوات ثابتة +20 و+50 و+100 أو خصمها؛ الترتيب يحسب تلقائيا حسب الدرجة.
- **الألحان:** العنوان، الوصف، الكلمات، الملاحظات، رابط يوتيوب، الترتيب، الصورة، التسجيل الأصلي، وتسجيل الأسرة.
- **الحروف القبطية:** شكل الحرف واسمه، كلمة المثال وترجمتها، ملاحظة، رابط شرح، الترتيب، الصورة، النطق، وملف ورقة إضافي.
- **دروس الطقس:** العنوان والوصف والنص والملاحظات والرابط والترتيب والصورة والصوت.
- **الإعدادات:** رابط مصدر القبطي، رسالة للأهل، تنزيل/استيراد نسخة من محتوى النصوص، وإعادة أمثلة البداية.

حقل الترتيب يقبل رقما؛ الأرقام الأصغر تظهر أولا. حذف أي سجل يحتاج تأكيدا. الملفات الكبيرة لها حدود حجم ويجري ضغط الصور قدر الإمكان عند حفظها.

### أمثلة ووسائط العرض

الأسماء والمحتوى الموجودان في `js/data.js` أمثلة أولية قابلة للتعديل. روابط يوتيوب الافتراضية هي **صفحات نتائج بحث تجريبية** وليست اعتمادا لمصدر كنسي بعينه. `assets/audio/demo-tone.wav` نغمة قصيرة لاختبار مشغل الصوت فقط؛ ليست تسجيلا حقيقيا لأي لحن أو نطق قبطي، وتظهر الواجهة تنبيها بذلك. استبدلها بتسجيلات موثوقة من لوحة الإدارة.

## التخزين والأمان والنسخة الحالية

- النصوص والإعدادات والدرجات: `localStorage`، على **نفس المتصفح ونفس النطاق**.
- الصور والصوت وملفات أوراق العمل: IndexedDB المحلي، على الجهاز نفسه.
- تحديث الصفحة لا يحذف التغييرات، لكن مسح بيانات الموقع/المتصفح، تغيير المتصفح أو الجهاز، أو تغيير النطاق يفقد الوصول إلى بيانات ذلك المتصفح.
- لا يوجد Backend، مزامنة، حسابات أطفال، صلاحيات مستخدم فعلية، أو تخزين مركزي للملفات. تسجيل دخول لوحة الإدارة واجهة تجريبية؛ بيانات الاعتماد مكشوفة للعميل. لوحة النتائج للقراءة فقط في واجهة الطفل، لكن أي تخزين عميل يمكن العبث به عبر أدوات المطور.
- النسخة الاحتياطية JSON تشمل السجلات النصية والإعدادات فقط؛ **لا تشمل الوسائط** في IndexedDB.

### قبل استخدامه علنا أو عبر عدة أجهزة

اربطه بخدمة Backend مناسبة، مثل Supabase (Auth + Postgres + Storage) أو API موثوق مع قاعدة بيانات وتخزين ملفات. نفذ صلاحيات حقيقية في الخادم/قواعد البيانات، واجعل تعديل المحتوى وإدارة النتائج للمدير المصرح به فقط. خزن مفاتيح الخدمة السرية في متغيرات بيئة Vercel وعلى الخادم، وليس في `config.js`. يمكن حينها استبدال طبقة `storage.js` بمحول API وتخزين روابط الوسائط البعيدة مع إبقاء مكونات العرض مستقرة.

## الوصول والاستجابة

- اللغة الأساسية عربية واتجاه الصفحة `rtl`، مع خط Tajawal وخط Coptic من Google Fonts وبدائل نظامية.
- تخطيط مرن للهاتف واللوحي والحاسوب، وأهداف لمس واضحة، وتسميات حقول وأزرار دلالية، وتركيز لوحة مفاتيح مرئي.
- أنيميشن قصيرة مع احترام `prefers-reduced-motion`.
- زر **اطبع الورقة** يطبع ورقة الحرف فقط عبر قواعد `@media print`، ويخفي عناصر الموقع الأخرى.

## اختبار سريع بعد التعديل

1. افتح الرئيسية ثم جرب الألحان، تفاصيل لحن، زر رجوع، الطقس، درس، القبطي، حرف، زر الطباعة والعودة للرئيسية.
2. افتح لوحة الإدارة وسجل الدخول بقيم `js/config.js`، ثم جرب إضافة/تعديل/حذف محتوى وطلاب، وتعديل النقاط بخطوات +20 أو +50 أو +100.
3. حدث الصفحة وتأكد من بقاء التعديلات، ومن ترتيب الطلاب التنازلي حسب الدرجة.
4. جرب ملف صوت وصورة صغيرين، وافتح المصدر على يوتيوب. تحقق أن رابطا غير تابع ليوتيوب يرفض.
5. اختبر الطباعة من تفاصيل حرف، ثم راجع التصميم بعرض هاتف ولوحي وحاسوب.
6. افتح DevTools Console أثناء التصفح لمراجعة أخطاء JavaScript أو الملفات غير المتاحة.
