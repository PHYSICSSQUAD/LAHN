# لحن — نتعلم ونرنم معا

منصة تعليمية عربية مرحة للأطفال والأسرة، مبنية بـ **HTML وCSS وVanilla JavaScript** فقط. الواجهة RTL بالكامل، وتعمل كتطبيق صفحة واحدة خفيف بروابط hash؛ لا تحتاج إلى خادم تطبيق أو build step، وجاهزة للنشر كملفات static على Vercel.

الموقع يخدم **ثلاثة فصول** (Baby Class وKG1 وKG2) من نفس الكود: صفحة اختيار أولى، ولكل فصل ثيمه اللوني وملاكه وقاعدة بياناته المحلية المستقلة، مع لوحات إدارة منفصلة لكل فصل ولوحة عامة للمدير العام تضم **صفحة تواصل**.

> **مهم:** هذه النسخة تعمل بنمط العرض المحلي. محتوى الإدارة والملفات المرفوعة يحفظ في متصفح الجهاز الحالي فقط، ولا ينتقل تلقائيا إلى زوار الموقع أو أجهزة أخرى. كما أن دخول الإدارة في واجهة أمامية وحدها ليس وسيلة حماية حقيقية. راجع قسم [التخزين والأمان](#التخزين-والأمان-والنسخة-الحالية) قبل نشر بيانات حقيقية.

## تشغيل المشروع محليا

تحتاج إلى Python 3 أو أي خادم static بسيط. من مجلد المشروع:

```bash
python3 -m http.server 4173
```

ثم افتح <http://localhost:4173>. لا تفتح `index.html` مباشرة عبر `file://` لأن المتصفح يمنع بعض وحدات JavaScript وميزات التخزين هناك.

لا توجد تبعيات npm ولا أمر build.

## الحسابات

كل الحسابات **تجريبية** ومكتوبة مرة واحدة في `js/config.js` داخل `APP_CONFIG`.

| الحساب | كلمة المرور | الصلاحيات |
| --- | --- | --- |
| `admin` | `ابي سيفين` | **مدير عام:** كل الفصول + صفحة التواصل |
| `babyclass` | `112233` | مدير فصل Baby Class فقط |
| `kg1` | `445566` | مدير فصل KG1 فقط |
| `kg2` | `778899` | مدير فصل KG2 فقط |

- مدير الفصل يعدل فصله فقط: الموارد (الأبطال والنقاط)، الألحان، الحروف القبطية، دروس الطقس، وإعدادات فصله (رابط المصدر ورسالة الأهل والنسخ الاحتياطي).
- مدير الفصل **لا** يستطيع فتح لوحة فصل آخر: أي محاولة تعيده إلى لوحة فصله، ولا تظهر له أقسام «الفصول» أو «صفحة التواصل».
- المدير العام يرى **شريط تبديل الفصول** فوق لوحة الإدارة (وداخل صفحات الفصول أثناء التصفح)، ويستطيع تعديل أي فصل، بالإضافة إلى قسم **صفحة التواصل** الذي لا يظهر لمديري الفصول.
- علامة الدخول تحفظ في `sessionStorage` وتنتهي عند إغلاق جلسة المتصفح.

اسم المدرسة الظاهر في الشريط العلوي لكل الصفحات («مدرسة شمامسة كنيسة الشهيد العظيم ابي سيفين بحدائق القبة») يضبط من `APP_CONFIG.siteBanner` في `js/config.js`.

## المسارات

| المسار | الوصف |
| --- | --- |
| `#/` | صفحة اختيار الفصل: أربع بطاقات (Baby Class، KG1، KG2، Admin) |
| `#/<class>/home` | رئيسية الفصل بثيمه وملاكه ولوحة أبطاله |
| `#/<class>/hymns` · `#/<class>/hymn?id=…` | الألحان وتفاصيل اللحن |
| `#/<class>/coptic` · `#/<class>/letter?id=…` | الحروف القبطية وتفاصيل الحرف |
| `#/<class>/liturgy` · `#/<class>/ritual?id=…` | دروس الطقس وتفاصيل الدرس |
| `#/<class>/admin` | لوحة إدارة الفصل |
| `#/admin` | لوحة المدير العام (كل الفصول + صفحة التواصل) |
| `#/contact` | صفحة «تواصل معي» العامة |

حيث `<class>` هو `babyclass` أو `kg1` أو `kg2`.

**الروابط القديمة بدون فصل** (`#/hymns`، `#/coptic`، `#/hymn?id=…`، `#/admin` …) تكمل تلقائيا في **آخر فصل تم فتحه** على هذا المتصفح مع الحفاظ على الصفحة والمعاملات، وإن لم يكن هناك فصل سابق تظهر **صفحة اختيار الفصل**. البيانات القديمة المحفوظة في `lahn-learning-data-v1` تنسخ مرة واحدة إلى فصل KG1 (`lahn-class-data-v2:kg1`) ثم يزال المفتاح القديم، فلا تضيع تعديلات النسخة السابقة.

## صفحة «تواصل معي» — `#/contact`

- رابطها موجود في **تذييل كل الصفحات** (في كل الفصول وصفحة الاختيار).
- تعرض: الاسم، الصفة، رسالة الترحيب، الهاتف، واتساب، البريد الإلكتروني، فيسبوك، العنوان، ومواعيد التواصل.
- الروابط تفاعلية عند صلاحيتها: `tel:` للهاتف، `https://wa.me/<number>` للواتساب، `mailto:` للبريد، ورابط فيسبوك بعد التحقق من النطاق.
- يحررها **المدير العام فقط** من قسم «صفحة التواصل» في `#/admin`، وتظهر التعديلات فورا في `#/contact`.
- تُحفظ في مفتاح مستقل اسمه `lahn-site-data-v1` (مشترك بين كل الفصول).

## ما الذي يعمل في الموقع؟

- الرئيسية: صفحة اختيار الفصل ثم رئيسية كل فصل ببطاقات كبيرة للألحان والطقس والقبطي، ولوحة أبطال مرتبة تلقائيا بالنقاط.
- الألحان: بطاقات قابلة للإدارة، وصفحة تفاصيل بها مشغل صوت، مصدر يوتيوب، كلمات، تسجيل إضافي وملاحظات.
- القبطي: مجموعة الحروف التجريبية، صفحات للحرف والصوت/المثال/الترجمة، ورقة عمل قابلة للطباعة، ورابط مصدر عام.
- الطقس: دروس قصيرة قابلة للإضافة والتحرير، مع نص وصوت وملاحظات وصور ومصدر يوتيوب.
- لوحات الإدارة: إدارة الطلاب والألحان والحروف ومصادر يوتيوب ودروس الطقس؛ إضافة وتعديل وحذف وترتيب، مع تأكيد قبل الحذف. كل فصل له بياناته ولوحته، وللمدير العام شريط تبديل بين الفصول وصفحة تواصل.
- تعديل نقاط الطلاب بخطوات ثابتة فقط: +20 أو +50 أو +100، ويمكن الخصم بالقيم نفسها. يعاد ترتيب لوحة الأبطال تلقائيا.
- مشغل صوت HTML5 موحد بعملية تشغيل/إيقاف مؤقت وشريط تقدم ووقت.
- رفع صور مضغوطة إلى WebP (حيث يدعم المتصفح ذلك)، وصوت وملفات PDF/صور لورقة العمل.
- الروابط الخارجية تفتح في نافذة جديدة وتقبل روابط YouTube / youtu.be الآمنة فقط.
- التغييرات المحفوظة والنجوم التعليمية تبقى بعد تحديث الصفحة على المتصفح نفسه، ولكل فصل بياناته منفصلة.

### شكل البيانات والمفاتيح

| المفتاح | المحتوى |
| --- | --- |
| `lahn-class-data-v2:<class>` | كل بيانات التعلم لفصل واحد: `students`, `hymns`, `copticLetters`, `liturgy`, `settings`, `progress` |
| `lahn-site-data-v1` | بيانات الموقع المشتركة (صفحة التواصل) |
| `lahn-last-class-v1` | آخر فصل تم فتحه، لتكملة الروابط القديمة |
| `lahn-admin-session-v1` | جلسة الدخول (اسم الحساب ودوره وفصله) |

كل سجل له `id` و`order`، ودرجات الطلاب تفرز تنازليا تلقائيا. حقول الوسائط تشير إلى معرفات IndexedDB بدل وضع الملفات الثنائية في HTML أو JSON، ومكتبة الوسائط مشتركة بين الفصول مع بقاء معرفات كل فصل داخل بياناته.

هذه الواجهة معزولة في `storage.js` لتسهيل استبدالها لاحقا بـ API وقاعدة بيانات من دون إعادة كتابة صفحات العرض.

## إدارة المحتوى

- **الأبطال والنقاط:** أضف أو حرر اسم الطالب. يبدأ الطالب الجديد بصفر، وتعديل النقاط متاح بخطوات ثابتة +20 و+50 و+100 أو خصمها؛ الترتيب يحسب تلقائيا حسب الدرجة.
- **الألحان:** العنوان، الوصف، الكلمات، الملاحظات، رابط يوتيوب، الترتيب، الصورة، التسجيل الأصلي، وتسجيل الأسرة.
- **الحروف القبطية:** شكل الحرف واسمه، كلمة المثال وترجمتها، ملاحظة، رابط شرح، الترتيب، الصورة، النطق، وملف ورقة إضافي.
- **دروس الطقس:** العنوان والوصف والنص والملاحظات والرابط والترتيب والصورة والصوت.
- **الإعدادات:** رابط مصدر القبطي، رسالة للأهل، تنزيل/استيراد نسخة من محتوى النصوص، وإعادة أمثلة البداية — كل ذلك **للفصل المفتوح فقط**.
- **صفحة التواصل** (المدير العام): بيانات الاسم والصفة والرسالة والهاتف والواتساب والبريد وفيسبوك والعنوان والمواعيد، مع استعادة النموذج الأصلي.

حقل الترتيب يقبل رقما؛ الأرقام الأصغر تظهر أولا. حذف أي سجل يحتاج تأكيدا. الملفات الكبيرة لها حدود حجم ويجري ضغط الصور قدر الإمكان عند حفظها.

### أمثلة ووسائط العرض

الأسماء والمحتوى الموجودان في `js/data.js` أمثلة أولية قابلة للتعديل، وهي مختلفة لكل فصل. روابط يوتيوب الافتراضية هي **صفحات نتائج بحث تجريبية** وليست اعتمادا لمصدر كنسي بعينه. `assets/audio/demo-tone.wav` نغمة قصيرة لاختبار مشغل الصوت فقط؛ ليست تسجيلا حقيقيا لأي لحن أو نطق قبطي، وتظهر الواجهة تنبيها بذلك. استبدلها بتسجيلات موثوقة من لوحة الإدارة.

## النشر على Vercel

1. اربط مستودع GitHub بمشروع جديد في Vercel.
2. اترك إعدادات Framework على **Other**، وBuild Command وOutput Directory فارغين/افتراضيين.
3. انشر مجلد المستودع كما هو؛ `index.html` هو نقطة الدخول، والروابط الداخلية تستخدم `#/...` فلا تحتاج إلى إعداد rewrite.

**متغيرات البيئة:** لا توجد متغيرات مطلوبة في النسخة الحالية. لا تضع مفاتيح أو أسرارا في JavaScript للمتصفح.

> النشر على Vercel لا يحول `localStorage` أو IndexedDB إلى قاعدة بيانات مشتركة. يرى كل زائر بيانات المتصفح الخاص به؛ لذلك يلزم ربط Backend قبل استخدام الموقع كمصدر محتوى مشترك.

## التخزين والأمان والنسخة الحالية

- النصوص والإعدادات والدرجات: `localStorage` لكل فصل على حدة، على **نفس المتصفح ونفس النطاق**.
- الصور والصوت وملفات أوراق العمل: IndexedDB المحلي، على الجهاز نفسه.
- تحديث الصفحة لا يحذف التغييرات، لكن مسح بيانات الموقع/المتصفح، تغيير المتصفح أو الجهاز، أو تغيير النطاق يفقد الوصول إلى بيانات ذلك المتصفح.
- لا يوجد Backend، مزامنة، حسابات أطفال، صلاحيات مستخدم فعلية، أو تخزين مركزي للملفات. تسجيل دخول لوحات الإدارة واجهة تجريبية؛ بيانات الاعتماد مكشوفة للعميل، ومن يعرف المفاتيح يستطيع تجاوزها من أدوات المطور. **لا تنشر كلمة مرور حقيقية ولا تعتمد على هذه الحماية لموقع عام.**
- النسخة الاحتياطية JSON تشمل السجلات النصية والإعدادات للفصل الواحد فقط؛ **لا تشمل الوسائط** في IndexedDB، ولا تشمل بيانات صفحة التواصل.

### قبل استخدامه علنا أو عبر عدة أجهزة

اربطه بخدمة Backend مناسبة، مثل Supabase (Auth + Postgres + Storage) أو API موثوق مع قاعدة بيانات وتخزين ملفات. نفذ صلاحيات حقيقية في الخادم/قواعد البيانات (دور لكل فصل ودور عام)، واجعل تعديل المحتوى وإدارة النتائج للمدير المصرح به فقط. خزن مفاتيح الخدمة السرية في متغيرات بيئة Vercel وعلى الخادم، وليس في `config.js`. يمكن حينها استبدال طبقة `storage.js` بمحول API وتخزين روابط الوسائط البعيدة مع إبقاء مكونات العرض مستقرة.

## الوصول والاستجابة

- اللغة الأساسية عربية واتجاه الصفحة `rtl`، مع خط Tajawal وخط Coptic من Google Fonts وبدائل نظامية.
- تخطيط مرن للهاتف واللوحي والحاسوب، وأهداف لمس واضحة، وتسميات حقول وأزرار دلالية، وتركيز لوحة مفاتيح مرئي.
- أنيميشن قصيرة مع احترام `prefers-reduced-motion`.
- ألوان كل فصل تدار عبر متغيرات CSS على `html[data-class]`، ويحدث لون شريط المتصفح (`theme-color`) مع الفصل المفتوح.
- زر **اطبع الورقة** يطبع ورقة الحرف فقط عبر قواعد `@media print`، ويخفي عناصر الموقع الأخرى.

## اختبار سريع بعد التعديل

1. من صفحة الاختيار `#/` افتح الفصول الثلاثة وتأكد من اختلاف الثيم والملاك، ومن ظهور شريط اسم المدرسة أولا في كل صفحة.
2. سجل الدخول بحساب فصل (مثلا `kg1` / `445566`)، وأضف طالبا أو لحنا، ثم تأكد أن التعديل ظهر في صفحات الفصل نفسه وأنه **لا يظهر** في فصل آخر، وأن محاولة فتح لوحة فصل آخر تعيدك لفصلك.
3. سجل الدخول بـ `admin` / `ابي سيفين`، وجرب شريط تبديل الفصول، وحرر بيانات صفحة التواصل ثم افتح `#/contact` للتأكد من ظهورها والروابط `tel:` و `wa.me` و `mailto:`.
4. جرب رابطا قديما بدون فصل (مثل `#/hymns`) وتأكد أنه يكمل في آخر فصل مفتوح أو يعود لصفحة الاختيار.
5. حدث الصفحة وتأكد من بقاء التعديلات، ومن ترتيب الطلاب التنازلي حسب الدرجة.
6. جرب ملف صوت وصورة صغيرين، وافتح المصدر على يوتيوب. تحقق أن رابطا غير تابع ليوتيوب يرفض.
7. اختبر الطباعة من تفاصيل حرف، ثم راجع التصميم بعرض هاتف ولوحي وحاسوب.
8. افتح DevTools Console أثناء التصفح لمراجعة أخطاء JavaScript أو الملفات غير المتاحة.
